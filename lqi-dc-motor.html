EL5010 · optimal & robust control

Teaching a motor to hold its position, even when you push back

An LQI (LQR plus integral action) position controller for a real DC motor rig, paired with a Kalman filter to keep the control signal steady even with noisy sensors.

Team · 4 members Platform · Quanser QNET DC motor + NI LabVIEW Tooling · MATLAB / Simulink

Overview

Two goals that quietly fight each other

Push a motor to correct its position fast, and it tends to overshoot, draw more current, and wear the hardware harder. Make it gentle, and it corrects slowly. This project set out to find a middle ground for a real DC motor: eliminate steady-state error completely, without letting the control signal saturate the actuator.

The tool for that balance is LQI: a Linear Quadratic Regulator with an added integrator state, tuned via the Discrete Algebraic Riccati Equation. Since the position sensor reading is noisy, a Kalman filter sits in front of the controller to smooth the state estimate before it's ever acted on.

How it works

An extra memory state that refuses to forget the error

A plain LQR controller can leave a small permanent offset between where the motor sits and where it's told to sit, because it only reacts to the current error. LQI fixes that by augmenting the state-space model with an integrator: a new state that keeps accumulating the tracking error over time. As long as that accumulated error is nonzero, the controller keeps nudging the motor, so the steady-state error is driven to zero by construction.

Technical detail: Riccati equation, gain, and the Kalman filter

The DC motor's electrical (KVL) and mechanical (Newton's law for rotation) equations are combined into a continuous state-space model, then discretized with zero-order hold to match the sampling rate used on the National Instruments hardware.

  • Gain design: the augmented state-space model (physical states plus the integrator state) is solved through the Discrete Algebraic Riccati Equation to get the optimal feedback gain, balancing tracking performance against control effort via the Q and R weighting matrices.
  • State estimation: since only position is measured directly, a Kalman filter predicts and corrects the full state (position, velocity, current) at every step, weighted by how much the model versus the sensor reading is trusted.

Five Q/R combinations were swept in MATLAB simulation first, then the best-behaved ones were re-run on the physical rig through LabVIEW, with and without an injected disturbance.

Results

The real motor tracked a square wave with almost no lag

On the physical rig, the best tuning combination settled within 0.1 seconds of each setpoint change with only 8.65% overshoot and a steady-state error of just 0.0016 radians, close enough to be read as flat on the position plot. A more conservative tuning traded that speed for softness: 0.4 second settling time, but a larger steady-state error of 0.0254 radians.

What the numbers traded off

Every tuning that reacted faster also drew a sharper voltage spike at each setpoint change. The best all-round combination wasn't the most aggressive one, it was the one that kept the response fast while leaving the control voltage comfortably inside its linear range.

Conclusion

The integrator did exactly what the theory promised

Adding integral action to the LQR effectively drove the steady-state error to near zero on real hardware, not just in simulation. The Kalman filter noticeably smoothed the position estimate compared to the raw sensor signal, and the DARE-derived gains gave a tunable dial between response speed and control effort, without ever pushing the input voltage into saturation.
